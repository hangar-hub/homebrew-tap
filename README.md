# Hangar Homebrew tap

Homebrew cask for [Hangar](https://github.com/hangar-hub/hangar), a self-hosted home for your machine learning models and datasets.

```sh
brew install hangar-hub/tap/hangar
```

The release workflow in `hangar-hub/hangar` updates `Casks/hangar.rb` on every release. Don't edit it by hand.
